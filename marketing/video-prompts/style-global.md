# Style global

Tempel blok ini di **akhir setiap prompt shot**.

```
Style: premium 3D motion-graphics animation, soft clay-like materials, smooth
cinematic camera moves, 60fps feel, gentle easing (ease-in-out), no jitter,
no morphing. Color palette strictly: Vanilla Custard #FEEFB6, Pale Sky #C3DAE8,
Deep Mocha #432F2E, with off-white #FFFDF6 backgrounds. Rounded UI cards with
large corner radius, pill-shaped buttons, clean modern SaaS aesthetic, soft
studio lighting, subtle shadows, shallow depth of field. Floating soap bubbles
and water droplets as recurring motif. No real logos, no readable text unless
specified, no people's faces.
```

## Tambahan untuk versi vertikal (9:16 — Reels, TikTok, Shorts)

```
vertical 9:16 composition, subject centered, safe margins top and bottom for captions
```

## Negative prompt (jika model mendukung)

```
text artifacts, garbled letters, distorted cars, extra wheels, flicker,
jitter, low quality, watermark, real brand logos, human faces
```
