# Prompt Video Promosi — Sparkle Wash

Kumpulan prompt untuk membuat video promosi dengan generator video AI (Higgsfield, Kling, Veo, Sora, Runway, dll).

| File | Untuk siapa | Tujuan CTA |
|---|---|---|
| [01-pemilik-usaha.md](01-pemilik-usaha.md) | Pemilik usaha cuci mobil/motor (calon pembeli aplikasi) | Coba gratis / chat WhatsApp |
| [02-pelanggan.md](02-pelanggan.md) | Pelanggan cuci kendaraan | Booking online sekarang |
| [style-global.md](style-global.md) | Dipakai di semua prompt | — |

## Cara pakai

1. **Prompt visual sengaja ditulis dalam bahasa Inggris.** Model video AI lebih akurat dengan bahasa Inggris. Voice over (VO) dan teks di layar tetap bahasa Indonesia.
2. **Satu prompt = satu shot (±5 detik).** Kebanyakan model hanya menghasilkan 5–10 detik per klip. Buat tiap shot terpisah, lalu sambung di editor (CapCut / Premiere / DaVinci).
3. **Tempel isi `style-global.md` di akhir setiap prompt shot**, supaya warna dan gaya konsisten.
4. **Teks di layar ditambahkan saat editing**, bukan diminta ke model video. Model AI sering merusak huruf dan angka.
5. Agar hasil lebih konsisten, pakai **image-to-video**: buat dulu gambar awal tiap shot, lalu animasikan.
6. Sambung antar-shot dengan elemen yang sama (gelembung pecah, zoom ke layar HP) supaya transisinya mulus.
